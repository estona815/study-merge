최종 공개일: 2026-06-09

앱 사용 지원

싸괄은 브라우저 안에서 괄사 루틴, 타이머, 기록, 압축 사진, 백업 파일을 관리하는 로컬 우선 앱입니다.

  • 앱이 열리지 않으면 브라우저 새로고침 후 다시 시도하세요.
  • 설정 화면의 업데이트 확인을 사용하면 새 캐시 적용 여부를 확인할 수 있습니다.
  • 알림은 브라우저와 기기 권한 상태에 따라 제한될 수 있습니다.

데이터 삭제

  • 설정 화면에서 사진만 삭제, 기록 삭제, 전체 앱 데이터 초기화를 할 수 있습니다.
  • 백업 JSON은 사용자가 직접 만든 파일이므로, 기기나 클라우드 저장 위치에서 직접 삭제해야 합니다.
  • 앱에는 계정 서버가 없으므로 서버 계정 삭제 절차가 존재하지 않습니다.

사진과 권한

  • 전후 사진은 선택한 브라우저의 로컬 저장소에 압축본으로 저장됩니다.
  • 참고 가이드용 카메라/업로드 이미지는 참고 동선 표시용으로만 로컬 처리하며, 원본 카메라/업로드 이미지는 기록이나 백업에 저장하지 않습니다.
  • 카메라, 사진/파일, 알림 권한은 사용자가 해당 기능을 직접 시작할 때만 요청됩니다.

주의

이 앱은 일반적인 뷰티 루틴과 셀프케어 참고용입니다. 의료기기가 아니며 의료 조언, 진단, 치료, 질병 예방 목적이 아닙니다.

문의

지원 문의는 앱 배포자가 스토어 또는 웹사이트에 게시한 지원 채널을 통해 접수합니다. 문의 시 앱 이름, 빌드 번호, 사용 환경, 문제가 발생한 화면을 함께 알려주세요.
