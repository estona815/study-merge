# Privacy Policy Draft

Effective date: 2026-06-09

## Overview

괄사 루틴 is a local-first beauty self-care app. The current version does not use accounts, backend storage, analytics SDKs, advertising SDKs, payments, or third-party data sharing. It is not a medical, diagnostic, or treatment service.

## Data Stored On Your Device

The app may store the following in the current browser's local storage:

- Routine history
- Skin reaction selections
- Before/after feeling values
- Notes
- Custom routines
- Reminder settings
- Photo retention preference
- Compressed before/after photos selected by the user
- Reference route settings and completion summaries

Before/after photos are selected through the browser file picker and compressed in the browser before storage. The app does not upload photos.

The reference guide can use the camera or an uploaded image when the user starts that feature. These camera/upload images are processed locally to display reference routes only. The current implementation does not identify a person, verify identity, create biometric templates, diagnose skin condition, or predict future skin changes. Original camera/upload images are not saved to routine history or backups.

## Permissions

- Camera: requested only when the user starts the reference guide camera.
- Photos/files: used only when the user selects an image for a record or reference guide route.
- Notifications: requested only when the user turns on reminders.

## Backups

The app can generate JSON backup text or files. Backups are created by the user and stored wherever the user chooses. A full backup may include compressed before/after photos. A light backup excludes photos. Backup import is size-limited and validates the backup code before import or merge.

## Data Deletion

The settings screen includes controls to:

- Delete photos only
- Delete routine records
- Reset all local app data

Browser site-data settings may also remove all app data.

## Third Parties

The app code does not send user-entered data, photos, camera frames, records, or backups to third-party services. If the app is hosted on a web server, the hosting provider may process standard server logs according to that provider's policy.
