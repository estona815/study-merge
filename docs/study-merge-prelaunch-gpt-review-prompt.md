# Study Merge Prelaunch GPT Review Prompt

## 상태 요약

- 프로젝트명: `Study Merge`
- 제품 유형: Expo + React Native 기반의 2048형 학습 게임 MVP
- 핵심 루프: 관련 개념 블록을 밀고 합치고, 합성 시 퀴즈를 풀어 학습을 확정하는 구조
- 검수 기준일: `2026-06-28`

## 이번 개발 패스에서 완료한 항목

- 실제 앱 진입점을 `Study Merge`로 복구함
  - `App.tsx`가 더 이상 ADHD 배터리 플래너를 렌더링하지 않고 `src/StudyMergeApp.tsx`를 렌더링함
- 루트 앱 셸 추가
  - `src/StudyMergeApp.tsx`에서 `onboarding`, `category`, `subject`, `unit`, `game`, `review`, `stats`, `result` 화면을 상태 기반으로 라우팅함
- 세션 복구 로직 추가
  - `src/store/useAppStore.ts`에 `currentGame` persist를 포함시켜 앱 재실행 후 진행 중 게임을 복구함
  - 복구된 세션은 강제로 `paused = true` 상태로 올려서 타이머가 몰래 진행되지 않게 처리함
- 앱 백그라운드 전환 대응 추가
  - `AppState`를 사용해 앱이 비활성화되면 진행 중 게임을 자동 일시정지함
- 게임 화면 런타임 안정성 수정
  - `src/screens/GameScreen.tsx`에서 조건부 `return` 뒤에 존재하던 `useEffect` 위치를 정리해 훅 순서 불일치 가능성을 제거함
- 앱 메타데이터 정리
  - `app.json`의 이름, slug, scheme, 설명, 색상값을 `Study Merge` 기준으로 수정함

## 현재 남아 있는 출시 전 과제

- 콘텐츠 품질
  - 현재 개념/설명/퀴즈는 샘플 데이터 기반 MVP임
  - 실제 출시 전에는 공식 교육과정, 자격 시험 출제 기준, 저작권 검토가 필요함
- 브랜딩 자산
  - 앱 아이콘, 스플래시, 스토어 등록 이미지, 프로모션 스크린샷이 완성되지 않음
- 스토어/배포 설정
  - 번들 ID, 패키지명, 배포 계정, 실제 스토어 메타데이터 확정 필요
- 실기기 QA
  - iOS/Android 실기기 터치감, 세이프에어리어, 성능, 메모리, 복귀 동작 검수 필요
- 서비스 운영 요소
  - 계정, 동기화, 원격 분석, 운영용 콘텐츠 관리, 장애 대응 체계는 아직 없음
