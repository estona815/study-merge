# Seoul Beauty Week Submission Packet

작성 기준: 2026-06-10 KST

## Packet Scope

이 패키지는 서울뷰티위크 제출 또는 후속 검토 자료를 준비하기 위한 초안입니다. 제품 설명은 **일반 뷰티 셀프케어 PWA** 범위로만 유지합니다.

핵심 메시지:

- 뷰티테크: 정적 PWA, 단계별 타이머, 선택형 얼굴 참고 가이드, 오프라인 캐시
- 셀프케어: 사용자가 직접 고르는 괄사 루틴과 로컬 기록
- 로컬 개인정보 보호: 서버 계정 없이 현재 브라우저 안에서 저장 및 관리

## Files

- `submission-brief.md`: 제출 본문과 피칭용 핵심 메시지
- `privacy-safety-summary.md`: 로컬 데이터 처리와 사용자 제어 요약
- `qa-evidence.md`: 기준 빌드, 산출물, QA 증적
- `copy-claims-checklist.md`: 제출 문구 검수 체크리스트
- `submission-assets-checklist.md`: 제출 전 준비물 체크리스트

## Submission Boundaries

- 이 패키지는 제출 문구와 증적 정리용이며, 실제 접수 완료를 뜻하지 않습니다.
- 회사명, 대표자, 사업자 정보, 담당자 연락처, 전시 형태, 부스 운영 계획은 소유자가 입력해야 합니다.
- 앱스토어 제출 항목은 별도로 남아 있습니다: hosted privacy/support URL, native wrapper, signing, store console forms.
- 기존 릴리스와 스토어 산출물은 재생성하지 않았습니다.

## Copy Guardrail

사용 가능한 방향:

- 일반 뷰티 셀프케어 PWA
- 루틴 안내, 단계별 타이머, 로컬 기록
- 사용자가 선택한 사진 메모
- 얼굴 참고 가이드는 참고 동선 표시용
- 데이터는 현재 브라우저에 저장

피해야 할 방향:

- 외모 변화 약속
- 전후 변화 단정 표현
- 상태 평가처럼 읽히는 얼굴 가이드 설명
- 검증되지 않은 수치, 순위, 실적 표현
- 사용자가 직접 제어하지 않는 데이터 처리처럼 보이는 문구
