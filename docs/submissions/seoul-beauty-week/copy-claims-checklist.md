# Seoul Beauty Week Copy Claims Checklist

작성 기준: 2026-06-10 KST

## Approved Positioning

Use this framing across the application, product introduction, booth script, QR landing copy, screenshots, and pitch materials:

- General beauty self-care PWA
- Routine guide and timer
- Local routine log and optional photo note
- User-controlled reminders
- Browser-based reference route display
- Local-first data handling

## Copy Review

| Surface | Required Check | Status |
| --- | --- | --- |
| Product title | Stays within beauty self-care | To verify before submission |
| Short introduction | Describes routine, timer, log, and local storage only | To verify before submission |
| Long introduction | No external proof, ranking, or performance claim unless sourced | To verify before submission |
| Face guide copy | Limited to reference route display | To verify before submission |
| MediaPipe mention | Explained as a technical dependency, not a user-facing judgement | To verify before submission |
| Screenshot captions | Do not promise visible change | To verify before submission |
| Demo script | Describes user-controlled steps, not outcomes | To verify before submission |
| Booth poster | No dramatic transformation language | To verify before submission |
| Privacy copy | Matches local-first implementation basis | To verify before submission |
| Organizer form answers | Match the exact submitted demo and company information | To verify before submission |

## Allowed Wording Direction

- "뷰티 셀프케어 루틴을 기록하고 따라가기 위한 PWA"
- "단계별 타이머와 로컬 기록"
- "사용자가 선택한 사진 메모"
- "참고 동선을 화면에 표시"
- "데이터는 현재 브라우저에 저장"
- "알림은 사용자가 켠 경우에만 사용"

## Avoid Wording Direction

- Appearance change promises
- Before/after proof language
- Strong ranking or award language without source
- Face guide language that sounds like judgement
- Any claim that the app replaces professional advice
- Any claim that user data is synced or protected by a server when it is local-only

## Final Review Steps

Before final submission, review these materials:

- Application form text
- Product introduction
- Pitch deck
- Booth poster and QR landing copy
- Demo script
- Screenshot captions
- Privacy and support URL text
- Any press, SNS, or partner copy using the same materials
