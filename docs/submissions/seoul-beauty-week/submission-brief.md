# Seoul Beauty Week Submission Brief

작성 기준: 2026-06-10 KST

## One-Line

괄사 루틴은 브라우저 안에서 단계별 괄사 루틴, 타이머, 로컬 기록, 선택형 참고 동선 표시를 제공하는 일반 뷰티 셀프케어 PWA입니다.

## Short Description

괄사 루틴은 설치형 웹앱 형태의 뷰티 셀프케어 도구입니다. 사용자는 루틴을 고르고 타이머를 따라가며, 기록과 사진 메모를 현재 브라우저 안에서 관리할 수 있습니다. 선택형 얼굴 참고 가이드는 카메라나 업로드 이미지 위에 동선을 표시하는 보조 기능으로만 설명합니다.

## Product Narrative

괄사 루틴은 일상 뷰티 셀프케어를 가볍게 시작하고 꾸준히 기록할 수 있도록 만든 PWA입니다. 앱은 루틴 선택, 단계별 타이머, 완료 기록, 사진 메모, 백업/복원, 리마인더를 한 화면 흐름 안에서 제공합니다. 데이터는 기본적으로 현재 브라우저에 저장되며, 사용자가 직접 백업 파일을 만들거나 삭제할 수 있습니다.

얼굴 참고 가이드는 사용자가 직접 카메라 또는 파일을 선택한 경우에만 동작합니다. 이 기능은 화면 위에 참고 동선을 표시하기 위한 보조 기능이며, 원본 카메라/업로드 이미지는 기록이나 백업에 저장하지 않는 방향으로 설명합니다.

## Demo Flow

1. 앱 첫 화면에서 오늘 루틴 또는 루틴 목록을 연다.
2. 단계별 타이머를 시작하고 구간별 안내를 확인한다.
3. 선택 사항으로 얼굴 참고 가이드를 열어 동선 표시를 확인한다.
4. 완료 후 루틴 기록과 사진 메모를 저장한다.
5. 설정에서 로컬 저장, 백업, 삭제 옵션을 보여준다.
