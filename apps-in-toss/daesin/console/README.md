# 토스 콘솔 입력 자료

`metadata.json`은 콘솔에 옮겨 적을 출시 후보 문구와 파일 명세를 모아 둔 파일입니다. `대신`은 워크스페이스 `49499`, 미니앱 `53958`, 고정 `appName=daesin`으로 등록되어 있습니다.

- 기본 문안과 `생활 > 건강 > 건강 관리`, 검색 키워드는 콘솔에 임시저장했습니다.
- 라이트·다크 로고는 Toss CDN에 업로드했고 URL을 `metadata.json`과 `granite.config.ts`에 반영했습니다.
- 고객 문의 이메일은 실제 소유 주소를 확인한 뒤 기본 정보 단계에 입력해야 합니다.
- `console/store-assets`의 1932×828 썸네일과 636×1048 실제 앱 스크린샷 세 장 이상을 업로드해야 합니다.
- 현재 앱은 로그인·외부 API·결제·광고·영구 저장이 없어 정책 URL이 공통 필수로 노출되지는 않지만, 기능 범위가 바뀌면 개인정보·약관 요건을 다시 검토합니다.
- 출시 단계에서는 `.ait` 업로드, `5분 선택하기 / Pause choice / intoss://daesin/` 주요 기능 등록, QR 실기기 테스트를 완료한 뒤 검토 요청 직전에서 멈춥니다.

`assets/daesin/store`의 기존 이미지는 소재 참고용이며, 현재 AIT의 최종 콘솔 스크린샷으로 사용하지 않습니다.
